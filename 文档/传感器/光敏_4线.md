# 光敏电阻模块（4 线制）

> 代码在 `代码/ZeroCarbonFan_v2/ZeroCarbon/src/light.h`
> 状态：✅ **已上板验证**（2026-09-23）

## 一、接线：**只接 3 根线**

模块是 4 线制，但本项目**只用 AO，DO 空着不接**：

| 模块 | 接到 ESP32 | 说明 |
|---|---|---|
| **VCC** | **3.3V** | ⚠️ **不是 5V**！见下方「为什么必须 3.3V」 |
| **GND** | GND | |
| **DO** | **不接**（空着） | 省一个 GPIO |
| **AO** | **GPIO35** | 模拟输出。只读输入脚，正适合 ADC |

> ⚠️ 模块上 4 个针的**排列顺序以实物丝印为准** —— 厂商给的两份资料里编号方式略有出入。

### 为什么必须接 3.3V

模块的 DO 有 **10k 上拉到 VCC**。**接 5V 的话 DO 高电平就是 5V**，而 **ESP32 的 GPIO 不是 5V 容限**，长期接有打坏引脚的风险。

（本项目虽然没接 DO，但供电电压决定了整个模块的逻辑电平，所以还是按 3.3V 接。）

模块内部的 LM393 工作电压 2~36V，**3.3V 完全正常**。

## 二、模块内部电路（依据厂商原理图）

```
VCC ──[10K]──┬── 节点 ──[光敏电阻]── GND      （节点并联 104 电容）
             │
             ├──→ AO（模拟量，直接引出）
             │
             └── LM393 比较器的一个输入端
VR1 10K 电位器（板上蓝色那个）── 另一个输入端，调 DO 的翻转阈值
LM393 输出 ──┬──[10K]── VCC（上拉）
             ├──[1K]── 开关指示 LED ── VCC
             └──→ DO
```

**3 线制版本**只引出 VCC/GND/DO，**没有 AO** —— 只能判"亮/暗"两态，读不到强度。本项目用的是 4 线制 ✓

## 三、关键参数

### `LIGHT_AO_PIN = 35`

选 GPIO35 的理由：**只读输入脚**（正适合 ADC）、非 strapping（0/2/5/12/15）、非 Flash（6~11）、非 USB 串口（1/3），而且它在引脚图左列第 6 孔，**紧挨着 PM2.5 的 AO（第 7 孔）**，两个模拟输入凑成一条线。
（第 5 孔的 GPIO34 也是只读 ADC1 脚，留空备用 —— 原文这里写「GPIO34 已被 PM2.5 占用」是错的，PM2.5 的 AO 一直是 32。）

**必须用 ADC1** —— GPIO35 是 ADC1_CH7 ✓

### `LIGHT_DARK_PCT = 50`

亮度百分比**低于 50%** 就算「暗」。

网页上的「暗/亮」和「光照强度%」**都从这一个 AO 推出来**，没有第二条判定路径。

### AO 的方向：**高 = 暗**

**由分压拓扑直接决定**（不依赖 LM393 怎么接）：

```
VCC ──[10K]── 节点 ──[光敏电阻]── GND
```

天暗 → 光敏电阻阻值**变大** → 节点电压**变高** → AO 变大。

所以代码里算「亮度百分比」时要**取反**：
```cpp
pct = 100 - (raw * 100L) / 4095;   // AO 高 = 暗 → 取反才是「亮」
```

**这一点很省事**：不管 LM393 的同相/反相接法怎么变，AO 的方向都成立，**不用实测、不用猜**。

## 四、为什么只用 AO，不用 DO

| | **只用 AO**（本项目） | 只用 DO |
|---|---|---|
| 占用 GPIO | 1 个 | 1 个 |
| 能给网页什么 | ✅ **光照强度百分比** | ❌ 只有「亮/暗」两态 |
| **极性** | ✅ **没有极性问题** —— AO 高=暗 由拓扑决定 | ⚠️ 必须实测 |
| 阈值怎么调 | 代码里改常量 | 板上电位器拧 |

**DO 的极性是个坑**：厂商给的两份资料互相矛盾 —— 参考例程说 `val==LOW` 时"检测有信号"，但"有信号"是指天**亮**还是天**暗**，从字面读不出来。**用 AO 就完全绕开了这个问题。**

**代价**：失去「拧电位器就能调阈值」的硬件便利。但阈值放代码里反而更灵活（能做回差、多档）。

## 五、踩过的坑

### 1. 引脚图读不清时别硬猜，用「数值」判断方向

一开始想从原理图判断 LM393 的相位，但图上分辨不出来。

**后来发现根本不需要**：AO 的方向由分压拓扑决定，与比较器无关 ✓

### 2. 阈值常量名字要跟数据源一致

早期代码里同时有 DO 和 AO 两套判定，还写了个「切换电平看读数差」的自检 —— **那个自检在静止环境下必然误报**（环境没变，读数当然一样）。已经删掉。

### 3. 供电和 PM2.5 相反

**PM2.5 转接板要 5V，光敏模块要 3.3V** —— 两块板子挨着接的时候最容易搞混。
