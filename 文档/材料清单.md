## 四、值得注意的接线要点

1. **PM2.5 转接板已内含 10k/1k 分压（÷11）** —— GP2Y1014AU 是 5V 供电，VO 最高约 4V，直接进 GPIO34 会超它的绝对最大 3.6V。转接板把 VO 分压到 **1/11**（最高约 0.36V）再从 AO 引出，**代码里按 `DIVIDER_RESTORE = 11` 乘 11 还原**。
   - 串口 `raw` 应落在 **0 ~ 450**。若冲到 4000 以上 → 说明板上没有分压，**立刻断电**。
   - ⚠️ 原文这里写的「电压减半、软件乘 2 还原」**是错的**（早期照裸传感器估的），×2 会把电压压到 0.7V 以下、读数死死贴在 0。
2. **4 路继电器：低电平触发 + 光耦隔离 —— ⚠️ JD-VCC 跳线帽必须拔掉**
   - **拔跳线**，`VCC→3.3V`、`JD-VCC→5V`：光耦逻辑侧参考电压就是 3.3V，和 ESP32 输出**同电位** —— IN 给 HIGH 时**压差为 0**，光耦彻底关断，不抖不发热。
   - **留跳线**（逻辑侧和线圈侧共用 5V）：IN 给 HIGH 时还有 **1.7V 压差**，光耦可能微导通 → 继电器不完全释放、抖动、发热。
   - **上电不能误吸合**：`relay.h` 的 `relayInit()` 是**先写输出锁存器（HIGH）再 `pinMode(OUTPUT)`**。顺序反了的话，引脚会先输出默认低电平，而 LOW = 吸合 —— 上电瞬间四路一起「咔」一下。
   - 通道：**IN1=GPIO25　IN2=GPIO26　IN3=GPIO33　IN4=GPIO13**，都是输出脚、非 strapping、非 Flash、非串口。
   - （原版固件用的 `relayPin = GPIO 2` 是 strapping 脚，**本工程已不用**。）
3. **风扇是 12V 的，不能直接接 ESP32 引脚** —— 必须经继电器触点。ESP32 引脚只能驱动继电器线圈（且是 5V 模块，信号脚接 3.3V 逻辑）。
4. **5V 与 3.3V 要分开，两块传感器供电不一样**：
   - **5V**（DC-DC 统一供给）：PM2.5 转接板、**继电器的 JD-VCC（线圈侧）**
   - **3.3V**（板上稳压器）：**光敏模块 VCC**（它 DO 有 10k 上拉到 VCC，接 5V 会让 5V 电平进 GPIO，而 ESP32 GPIO 不是 5V 容限）、**继电器的 VCC（光耦逻辑侧）**、**DHT11**
   - ESP32 逻辑本身是 3.3V
5. **板子是 ESP32-WROOM-32 + CP2102 + TYPE-C**（38 脚双排）—— 完整引脚定义见 `文档/板卡/esp32_cp2102_引脚图.jpg`，**加新设备选引脚前先查这张**：
   - GPIO **0 / 2 / 5 / 12 / 15** 是 strapping 引脚（上电瞬间的电平决定启动模式、Flash 电压、启动日志），**别接继电器**——现有 `relayPin = GPIO 2` 就是这个隐患，加第二路时应一起挪到 **25 / 26 / 27 / 32 / 33**。其中 GPIO12 接错最危险：上电为高会让芯片按 1.8V Flash 供电启动，直接起不来。
   - GPIO **6–11** 接着板载 Flash（引脚图上标着 Flash CK/D0/D1/D2/D3/CMD），**绝对不能用**，占了就无法启动、也无法烧录。
   - GPIO **34 / 35 / 36 / 39**（图左上角，标 ADC0/3/6/7）**只能输入**、无内部上下拉 —— 按键/传感器输入可用，接继电器、LED 等输出设备不行。
   - ⚠️ **模拟输入（ADC）只认 ADC1 的脚：GPIO 32 / 33 / 34 / 35 / 36 / 39**。
     GPIO **0 / 2 / 4 / 12 / 13 / 14 / 15 / 25 / 26 / 27 属于 ADC2**，而 **ADC2 和 WiFi 共用硬件 —— 主程序一开热点，`analogRead()` 在这些脚上就失效**。
     引脚图上标 `ADC0`~`ADC7` 的是 ADC1，标 `ADC10`~`ADC19` 的是 ADC2，**一眼能分**。
     现有用法：PM2.5 的 AO → GPIO34（ADC6）｜光敏的 AO → GPIO35（ADC7）—— 都在 ADC1，开热点也能读。
     （数字用途不受此限：ILED → GPIO14 虽是 ADC2，但只做普通输出，没问题。）
   - GPIO **25 / 26** 是 DAC1 / DAC2（图上标着），用不上 DAC 时当普通输出没问题。
   - 引出的 UART：**GPIO1=TX0 / GPIO3=RX0**（USB 串口就走这对，**别占**）、GPIO16=RX2、GPIO17=TX2。

6. **当前 GPIO 分配总表**（加新设备前先查这张，避免撞车）：

   | GPIO | 接什么 | 类型 |
   |---|---|---|
   | **13** | 继电器 **IN4**（空调） | 数字输出 |
   | **14** | PM2.5 转接板 **ILED** | 数字输出 |
   | **25** | 继电器 **IN1**（进/排风扇） | 数字输出 |
   | **26** | 继电器 **IN2**（灯） | 数字输出 |
   | **27** | **DHT11** DATA | 数字双向 |
   | **32** | PM2.5 转接板 **AO** | 模拟输入（ADC1 ✅） |
   | **33** | 继电器 **IN3**（抽湿机） | 数字输出 |
   | **35** | 光敏模块 **AO** | 模拟输入（ADC1 ✅，只读脚） |

   **8 个脚各归其主，无冲突。** 空闲且安全的还有：**4 / 16 / 17 / 18 / 19 / 21 / 22 / 23 / 36 / 39**。
