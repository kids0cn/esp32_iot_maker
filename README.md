# 原目录名提供方物联网 — ESP32 智能家居模拟系统

> ESP32 作控制器的智能家居模拟系统：PM2.5 传感器联动进/排风扇，光伏 + 电池储能供电，AP 热点下用 Web 页面做手动/自动控制。

## 这是什么

一个用来**模拟真实智能家居系统**的演示装置。核心是用一颗 ESP32 当大脑，把「环境感知 → 自动决策 → 执行机构动作」这条链路完整跑通；供电侧用太阳能光伏板 + 电池模拟光伏发电与储能，让整套系统看起来是一台能离网自持的设备。

做成模拟/演示形态的意义在于：**功耗、联动逻辑、控制界面都在真实硬件上验证**，后续换到实际产品（原目录名物联网场景）时逻辑可直接复用。

## 系统组成

### 控制器
- **ESP32** —— 主控 + 联网
  - 提供 **AP 热点**服务：手机/电脑直连后浏览器访问 Web 页面，不依赖现场路由器
  - Web 页面提供**手动控制**（设备启停）和**自动模式**（依赖传感器检测）两种控制方式

### 传感器（感知侧）
| 传感器 | 用途 | 状态 |
|--------|------|------|
| PM2.5 传感器 | 回传颗粒物浓度，作为风扇启停判据 | 已规划（核心） |
| 光照传感器 | 自动亮灯 | 规划中 |
| 温湿度传感器 | 配合继电器模拟自动开除湿机 | 规划中 |

### 执行机构（动作侧）
| 设备 | 作用 | 状态 |
|------|------|------|
| 进风扇（带过滤芯） | 往里送风，**滤芯保证进风洁净** | 已规划 |
| 排风扇 | 把室内的风排出去 | 已规划 |
| 灯光 | 由光照传感器触发 | 规划中 |
| 除湿机（继电器模拟） | 由温湿度传感器触发 | 规划中 |

> 进风扇 + 排风扇构成**一进一排**的气流回路：进风过滤、排风换气。PM2.5 高时启动换气，恢复后停止。

### 供电系统
- **太阳能光伏板** —— 模拟光伏发电
- **电池** —— 模拟储能
- **附属设备** —— 充电/稳压等配套

整套系统由光伏 + 电池供电，用于演示「发电—储能—用电」的闭环。

## 功能

### 核心功能（当前目标）
1. **自动模式**：ESP32 采集 PM2.5 传感器数据 → 判断是否需要开风扇 → 驱动进风扇/排风扇启停
2. **手动模式**：连上 ESP32 的 AP 热点 → 打开 Web 页面 → 手动控制各设备启停
3. **AP + Web 控制台**：设备本身即热点，现场无需外部网络即可操作

### 规划中功能
4. **光照联动照明**：光照传感器检测到暗 → 自动亮灯
5. **湿度联动除湿**：温湿度传感器 + 继电器 → 模拟自动打开除湿机
