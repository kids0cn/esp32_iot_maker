# 中学生物联网创客项目 — ESP32 智能家居模拟系统

> 一个中学生创客项目：用 ESP32 做控制器，PM2.5 传感器联动进/排风扇，太阳能 + 电池模拟供电，ESP32 开 AP 热点，连上后用 Web 页面手动/自动控制设备。

## 这是什么

一个用来**模拟真实智能家居系统**的创客作品。核心是用一颗 ESP32 当大脑，把「环境感知 → 自动决策 → 执行机构动作」这条链路完整跑通；供电侧用太阳能光伏板 + 电池模拟光伏发电与储能，让整套系统看起来是一台能离网自持的设备。

做成模拟/演示形态的意义在于：**传感、联动逻辑、控制界面都在真实硬件上验证**。它是学嵌入式 + 物联网 + 一点点能源系统的综合练习，练的是把想法变成一个能跑、能演示、能讲清楚的实物。

## 系统组成（概览）

| 层 | 组成 |
|----|------|
| **控制器** | ESP32 —— 主控 + 联网，开 AP 热点，跑 Web 控制台 |
| **感知** | PM2.5 传感器（核心）；规划中：光照传感器、温湿度传感器 |
| **执行** | 进风扇（带过滤芯）、排风扇；规划中：灯光、除湿机（继电器模拟） |
| **供电** | 太阳能光伏板 + 电池 + 附属设备，模拟光伏发电与储能 |

> 进风扇 + 排风扇构成**一进一排**的气流回路：进风过滤、排风换气。PM2.5 高时启动换气，恢复后停止。

## 学习目标

- **嵌入式基础** —— GPIO 数字/模拟输入输出、传感器读数、风扇驱动
- **物联网** —— ESP32 AP 模式、内嵌 Web 服务器、HTTP 请求处理
- **控制逻辑** —— 阈值判断、自动/手动模式切换、状态机
- **能源概念** —— 光伏发电、电池充放电、负载与供电的匹配
- **工程习惯** —— 接线规范、代码分模块、调试与记录
